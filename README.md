# SajiloWear

SajiloWear is a web application developed to make traditional Nepali attire more accessible through a rental and sharing platform. The idea behind this project is to provide an affordable alternative to buying expensive traditional clothing that is usually worn only for special occasions.

The platform allows users to browse available attire, rent or share clothing, manage their profiles, and confirm payments. Owners can upload their attire, manage rental requests, and keep track of their listings through the system. An admin panel is also included to manage users, attire listings, and rental activities.

This project was developed using PHP, MySQL, HTML, CSS, and JavaScript as part of my academic learning in full-stack web development.

## Features

### User Features

- User registration and login
- Browse traditional Nepali attire
- View attire details
- Rent available attire
- Share attire for rent
- Manage user profile
- Payment confirmation
- View rental history

### Owner Features

- Upload new attire
- Update attire information
- Manage rental requests
- View booking details

### Admin Features

- Manage users
- Manage attire listings
- Monitor rental activities
- Manage the overall system

## Getting Started

### Requirements

- XAMPP
- PHP 8 or above
- MySQL
- Web Browser

### Installation

1. Clone this repository.

```bash
git clone https://github.com/yourusername/SajiloWear.git
```

2. Copy the project folder into the **htdocs** directory inside XAMPP.

3. Start Apache and MySQL from the XAMPP Control Panel.

4. Create a new database in phpMyAdmin.

5. Import the SQL file included in the project.

6. Update the database connection if required.

7. Open your browser and visit:

```
http://localhost/SajiloWear/
```
